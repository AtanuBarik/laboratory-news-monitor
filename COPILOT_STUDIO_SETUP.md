# Copilot Studio integration for the Laboratory News Monitor

## Repository details

- Owner: `AtanuBarik`
- Repository: `laboratory-news-monitor`
- Branch: `main`
- Primary structured data: `data/news.json`
- AI-friendly all-company file: `knowledge/latest.md`
- Company files:
  - `knowledge/labcorp.md`
  - `knowledge/quest-diagnostics.md`
  - `knowledge/arup-laboratories.md`
  - `knowledge/mayo-clinic-laboratories.md`
  - `knowledge/sonic-healthcare.md`
- File map and update timestamp: `knowledge/manifest.json`

The `knowledge` files are regenerated by GitHub Actions every six hours and whenever the `refresh_news` repository-dispatch event is triggered.

## Add the GitHub MCP tool in Copilot Studio

1. Open the agent in Microsoft Copilot Studio.
2. Enable **Generative orchestration** in the agent settings.
3. Open **Tools > Add a tool**.
4. Select **Model Context Protocol (MCP)** and add the GitHub MCP server.
5. Sign in with the GitHub account that can read this repository.
6. Where selective permissions are available, enable read-only operations such as file-content retrieval, repository browsing, and code search. Disable file writes, branch creation, issue creation, pull requests, and merges unless explicitly required.
7. Rename the tool to **Read Laboratory News Repository**.

Suggested tool description:

```text
Read the latest public clinical laboratory news from the GitHub repository
AtanuBarik/laboratory-news-monitor on the main branch.

Use knowledge/latest.md for cross-company questions. Use the relevant company
file under knowledge/ for company-specific questions. Use data/news.json only
when exact structured filtering or metadata is needed.
```

## Agent instructions

```text
You are a competitive-intelligence assistant focused on the US clinical
laboratory and reference laboratory market.

For every question about recent news, company activity, partnerships, products,
financial developments, acquisitions, research, regulation, reimbursement, or
leadership changes, read the GitHub repository before answering.

Repository:
- Owner: AtanuBarik
- Repository: laboratory-news-monitor
- Branch: main

Retrieval rules:
1. Read knowledge/manifest.json first when you need the latest repository update
   time or need to choose the correct file.
2. Read knowledge/latest.md for cross-company questions.
3. Read the appropriate company file for company-specific questions:
   - Labcorp: knowledge/labcorp.md
   - Quest Diagnostics: knowledge/quest-diagnostics.md
   - ARUP Laboratories: knowledge/arup-laboratories.md
   - Mayo Clinic Laboratories: knowledge/mayo-clinic-laboratories.md
   - Sonic Healthcare: knowledge/sonic-healthcare.md
4. Use data/news.json when exact JSON filtering is required.
5. Never answer a repository-news question from general knowledge without first
   checking GitHub.
6. Do not invent an article, date, company action, source, category, or URL.
7. When the user asks for the latest news without a date range, prioritize the
   most recent 30 days available.
8. Group duplicate reports covering the same underlying event.
9. For every development provide the company, headline, publication date,
   source, category, factual summary, strategic implication, and original URL.
10. Clearly separate factual reporting from strategic interpretation.
11. When the repository does not contain enough information, state:
   "No relevant information was found in the current GitHub news repository."
```

## Optional refresh tool

The workflow accepts a GitHub repository-dispatch event named:

```text
refresh_news
```

In Copilot Studio, add the GitHub connector action **Create a repository dispatch event** and configure:

- Owner: `AtanuBarik`
- Repository: `laboratory-news-monitor`
- Event type: `refresh_news`

Suggested tool name: **Refresh Laboratory News**

Suggested tool description:

```text
Trigger the GitHub news collection workflow. Use only when the user explicitly
asks to refresh, update, or fetch new news. Do not claim completion until a
subsequent GitHub read confirms a newer generated_at value.
```

## Web app embedding

After testing and publishing the Copilot Studio agent:

1. Open **Channels > Web app**.
2. Copy the complete embed code or the iframe `src` URL.
3. Add that URL to the GitHub dashboard's `index.html` in the floating AI panel.
4. Never place GitHub credentials, access tokens, or connector secrets in the HTML.
